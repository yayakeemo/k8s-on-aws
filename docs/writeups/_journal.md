# Live-Platform problem journal

Every real problem met on the live Platform is logged here **as it happens**, before it is
fixed or understood. These entries are the raw material for the troubleshooting write-ups
(FR-33). See `docs/conventions.md`, "Problem journal".

Add new entries at the bottom, one per problem, using this template:

````markdown
### YYYY-MM-DD — <short symptom title>

- **Date:** YYYY-MM-DD HH:MM UTC
- **session_id:** s20261028-1022 (or `none` if no Session was active)
- **Symptom:** what was observed, verbatim error text where possible
- **First commands:** the first commands run to investigate, with their relevant output

  ```sh
  <command>
  ```

- **Outcome / follow-up:** (optional, filled in later) cause, fix commit, write-up link
````
